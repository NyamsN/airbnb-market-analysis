## Duplicate review IDs
The 160 repeated `review_id` values each appear exactly twice, with the same date and reviewer, on two different listings. All 22 listings involved are in Rome, belong to 2 hosts, and form 11 pairs (an older listing and a newer one around ID 22,219,000), consistent with reviews carried over on re-listing. All rows were kept; (`listing_id`, `review_id`) is the composite key; listing-level counts keep each listing's records; market totals count each review once (5,372,983 unique events).

## Currency
No currency field. Mapping from the data dictionary ("in each country's currency"): Paris and Rome EUR, New York USD, Sydney AUD, Rio de Janeiro BRL, Istanbul TRY, Mexico City MXN, Bangkok THB, Cape Town ZAR, Hong Kong HKD. All price tests run within city; cross-city charts use price ÷ city median.
